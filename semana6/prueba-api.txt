Al enviar una petición POST a la ruta /registro con el siguiente JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor recibe los datos usando req.body.

La respuesta generada es:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto demuestra que la API recibe información enviada por el usuario y la devuelve como confirmación.
