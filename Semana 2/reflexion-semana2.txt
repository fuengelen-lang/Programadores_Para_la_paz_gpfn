Aprender a usar la terminal es importante porque permite trabajar de forma más rápida y organizada dentro de un proyecto. Los desarrolladores usan comandos para crear carpetas, archivos y navegar entre directorios fácilmente. También ayuda a automatizar tareas y manejar proyectos grandes. Con la terminal se pueden usar herramientas como Git para guardar cambios y trabajar en equipo. Aunque al principio parece difícil, practicar los comandos básicos facilita mucho el trabajo. Además, entender cómo funciona la terminal mejora las habilidades técnicas y la productividad. 
Esta actividad me ayudó a conocer comandos importantes y a comprender mejor cómo organizar archivos en un proyecto, aprendí a utilizar comandos básicos de la terminal y a trabajar con Git y GitHub y también aprendí a clonar un repositorio, editar archivos en Visual Studio Code y subir cambios a GitHub utilizando comandos, ayudandome a comprender mejor cómo organizar proyectos y trabajar con herramientas de programación.
